# On-Demand Skills (`/s` & `/skill`)

Drop `.md` skill files in this folder (`skills/on-demand/`) to make them searchable in chat.

### 1. Skill File Format (Line 1):
```markdown
# [SKILL] reviewer ---> review, check, audit, bug, code review
Your prompt instructions here...
```

### 2. Usage in Chat:
* **Search & Load:** `/s <query>` (e.g. `/s review`)
* **List All:** `/s`
* **Controls:** `↑` / `↓` navigate $\cdot$ `↵` load $\cdot$ `Esc` exit
